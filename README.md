# O₂ Odyssey mini-games

Playable builds of three browser mini-games on exercise physiology (Module 2 of the STAN EXP course): Baker Street, Remodel and The Fitting.

Play: open the GitHub Pages site for this repository; the landing page has one Play button per game. Each game is a single self-contained HTML file, nothing to install.

The games are published here as minified builds only. The source, art files and build scripts are not part of this repository.
